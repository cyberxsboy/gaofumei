# Contributing

Thank you for helping improve this repository.

## Guidelines

- Keep changes factual, clear, and relevant to the website.
- Correct broken links and outdated descriptions.
- Do not add claims about features or services that have not been verified.
- Do not publish credentials, API keys, private server details, or personal information.
- Avoid duplicate or unrelated promotional content.

## Reporting an Issue

Please include the affected file or URL, a description of the issue, and steps to reproduce it when applicable.

## Pull Requests

Keep changes focused and explain why each change is useful.
